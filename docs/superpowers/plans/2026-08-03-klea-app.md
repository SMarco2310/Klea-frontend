# Klea App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Klea — landing page, login/signup UI, and full dashboard (workspace + multi-app license/subscription management) — on the existing blank Nuxt 4 scaffold, wired to in-memory mock data, per `docs/superpowers/specs/2026-08-03-klea-app-design.md`.

**Architecture:** Nuxt 4 app-dir structure (`app/pages`, `app/layouts`, `app/components`, `app/composables`). Three layouts (`default`, `auth`, `dashboard`). All data lives in reactive in-memory composables seeded on load — no backend, no persistence. shadcn-vue supplies themed base primitives (Button, Input, Dialog, Tabs, Select, Badge, Switch, Table, DropdownMenu); everything else is custom Tailwind markup matching the dark-slate/sage-green visual system.

**Tech Stack:** Nuxt 4, Vue 3, Tailwind CSS v4 (via `@tailwindcss/vite`), shadcn-vue (Reka UI + `tailwind-variants`), Lucide icons (`lucide-vue-next`), Space Grotesk + DM Sans (Google Fonts).

## Global Constraints

- Dark-first theme, light mode must also pass 4.5:1 text contrast (spec §Visual system).
- Accent color is muted sage-green, not neon green (spec §Visual system).
- No emoji icons anywhere — Lucide SVG only (spec §Visual system).
- All interactive elements: `cursor-pointer`, visible focus ring, 150–300ms transitions, no layout-shifting hover transforms (spec §Visual system).
- Derived stats (e.g. success rate) must render `—` instead of a number when the underlying count is 0 (spec §Known UX issues).
- Empty states must include an actionable CTA, not just passive text (spec §Known UX issues).
- One consistent "active" nav-item treatment reused across top-level nav and sub-tabs (spec §Known UX issues).
- Secret/API-key inputs masked by default with a reveal toggle (spec §Known UX issues).
- Live mode must have its own visible banner/indicator, mirroring the Test-mode banner (spec §Known UX issues).
- No real backend, payment integration, webhook delivery, email sending, or persisted session — everything resets on full page refresh (spec §Explicit non-goals).
- No test framework is configured; verification is manual dev-server + browser check against the spec's pre-delivery checklist (responsive at 375/768/1024/1440px, contrast, no emoji icons, cursor-pointer, focus states) (spec §Testing).

```typescript
// app/composables/useAnalytics.ts
export function useAnalytics(appId: string) {
  const { subscriptions } = useSubscriptions(appId)
  const { subscribers } = useSubscribers(appId)

  const activeSubs = computed(
    () => subscribers.value.filter((s) => s.status === 'active').length
  )
  const revenue = computed(() =>
    subscriptions.value.reduce((sum, s) => sum + s.amount, 0)
  )
  const transactions = computed(() => subscriptions.value.length)
  const successRate = computed(() => {
    if (transactions.value === 0) return null
    const successful = subscriptions.value.filter((s) => s.status === 'active').length
    return Math.round((successful / transactions.value) * 100)
  })

  return { activeSubs, revenue, transactions, successRate }
}
```

```typescript
// app/composables/useEarnings.ts
export function useEarnings() {
  const { apps, subscriptions } = useSeedData()
  const { mode } = useEnvMode()

  const scopedTxns = computed(() => subscriptions.value.filter((s) => s.env === mode.value))

  const grossVolume = computed(() => scopedTxns.value.reduce((sum, s) => sum + s.amount, 0))
  const refunded = computed(() => 0)
  const totalBalance = computed(() => grossVolume.value - refunded.value)
  const transactionCount = computed(() => scopedTxns.value.length)
  const successfulCount = computed(
    () => scopedTxns.value.filter((s) => s.status === 'active').length
  )
  const avgTransaction = computed(() =>
    transactionCount.value === 0 ? null : grossVolume.value / transactionCount.value
  )
  const appCount = computed(() => apps.value.length)

  return {
    totalBalance,
    grossVolume,
    refunded,
    avgTransaction,
    transactionCount,
    successfulCount,
    appCount,
  }
}
```
